# CWE Top 25 Most Dangerous Software Weaknesses — 2025 (a.k.a. "CWE/SANS Top 25")

Source: https://cwe.mitre.org/top25/archive/2025/2025_cwe_top25.html (MITRE/CISA,
built from ~39k CVEs, Jun 2024–Jun 2025; verified 2026-10). New in 2025:
CWE-120, 121, 122, 284, 639, 770. CWE-78 has the most KEV entries.

"Vedha hotspot" = where this weakness most plausibly appears in this repo.
Memory-safety items (5, 7, 8, 11, 13, 14, 16) mostly apply to native code —
for Python/TS they matter in C extensions, parsers of scanner binaries' output
we shell out to, and any vendored native tool in `probe/tools`.

| # | CWE | Name | Vedha hotspot | Check / mitigation |
|---|---|---|---|---|
| 1 | CWE-79 | Cross-site Scripting | Frontend rendering scan output, banners, hostnames, CVE text, report HTML | React auto-escape; no `dangerouslySetInnerHTML` without DOMPurify; CSP (`lib/csp.ts`); escape in server-rendered reports/PDF/HTML exports |
| 2 | CWE-89 | SQL Injection | Backend filters/sorting/search, raw `text()` | ORM/bound params; sort/order columns from an allow-list, never raw strings |
| 3 | CWE-352 | CSRF | Cookie-authenticated state-changing routes | SameSite cookies + CSRF token or bearer-only auth; no state change on GET |
| 4 | CWE-862 | Missing Authorization | New routers/endpoints, WebSocket handlers, background job triggers | Auth + RBAC dependency on every route; test 401/403 |
| 5 | CWE-787 | Out-of-bounds Write | Native tools/extensions | Prefer memory-safe libs; keep native deps patched |
| 6 | CWE-22 | Path Traversal | Report/export download, artifact storage, probe file ops, archive extraction | Generate server-side names; resolve + `is_relative_to(base)`; zip-slip check on extraction |
| 7 | CWE-416 | Use After Free | Native code | Patch native deps |
| 8 | CWE-125 | Out-of-bounds Read | Native code, binary protocol parsers | Bounds checks in custom parsers (struct unpack lengths) |
| 9 | CWE-78 | OS Command Injection | **Probe scanners** wrapping nmap/etc., installer scripts, manager tooling | Arg lists, `shell=False`; validate targets with `ipaddress`/strict regex; `--` before positional args; no user data in shell scripts |
| 10 | CWE-94 | Code Injection | `eval`/`exec`, dynamic import from config, LLM-generated code, Jinja templates | Never eval untrusted data; sandboxed templates; allow-listed plugin names |
| 11 | CWE-120 | Classic Buffer Overflow | Native code | As above |
| 12 | CWE-434 | Unrestricted File Upload | Asset imports, evidence attachments, agent packages | Size cap, type allow-list by content (magic bytes) not extension, random stored names, outside web root, AV/parse in isolation |
| 13 | CWE-476 | NULL Pointer Dereference | Native; in Python the analogue is `None` crashes → DoS | Explicit None handling; Pydantic required fields |
| 14 | CWE-121 | Stack-based Buffer Overflow | Native code | As above |
| 15 | CWE-502 | Deserialization of Untrusted Data | msgpack/pickle/YAML between probe↔manager, cached objects, model files (joblib/pickle for ML) | JSON or schema-validated msgpack without ext hooks; `yaml.safe_load`; never unpickle untrusted; sign ML artifacts |
| 16 | CWE-122 | Heap-based Buffer Overflow | Native code | As above |
| 17 | CWE-863 | Incorrect Authorization | RBAC logic, portal scope, "admin of tenant X acts on tenant Y" | Central RBAC helpers; tests per role × action matrix |
| 18 | CWE-20 | Improper Input Validation | All boundaries (API, probe→manager results, imported files) | Strict Pydantic schemas; treat probe-submitted data as untrusted too |
| 19 | CWE-284 | Improper Access Control | Admin/ops endpoints, metrics, internal services exposed in compose | Network exposure review; authenticate internal endpoints |
| 20 | CWE-200 | Exposure of Sensitive Information | Error messages, logs, API responses returning whole ORM objects, credentials in scan configs | Response schemas (explicit fields); redact; generic errors |
| 21 | CWE-306 | Missing Authentication for Critical Function | Probe enrolment, agent endpoints, health/debug routes, WebSockets | Authenticate every critical function; enrolment tokens one-time |
| 22 | CWE-918 | SSRF | Integrations, webhooks, URL import, NVD/feed fetchers with configurable URLs, LLM tool use | Scheme + resolved-IP allow/deny, no redirect following to blocked ranges, egress allow-list |
| 23 | CWE-77 | Command Injection (generic) | Command strings passed to tools, AD tooling (impacket), templated commands sent manager→probe | Structured commands, allow-listed verbs, signed manager→probe instructions |
| 24 | CWE-639 | Authorization Bypass Through User-Controlled Key (IDOR) | `/{id}` routes for assets, scans, findings, reports | Always `WHERE id = :id AND tenant_id = :principal_tenant` |
| 25 | CWE-770 | Allocation of Resources Without Limits | Pagination, uploads, scan concurrency, WebSocket fan-out, LLM token spend, regexes | Caps on page size/body size/concurrency/tokens; rate limiter (`app/ratelimit.py`); timeouts |
