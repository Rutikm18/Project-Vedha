## The one-sentence version

> Vedha is the only network VA platform where **the vulnerability database never enters the
> client's network, findings are anti-false-positive by construction, and you can re-detect
> against today's CVEs without re-scanning** — which makes it the natural infrastructure for
> MSSPs, security consultancies, and data-sovereign / OT environments.

## A note on rigor

Market-size figures in doc 01 are **directional estimates for framing**, not sourced analyst
numbers — they are labeled as such and flagged `[VALIDATE]` where a real number should replace
them before any board/investor use. Everything about **Vedha's own capabilities and gaps** is
grounded in the current codebase and is safe to quote.
